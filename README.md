# Distributed Systems Exercises 2025

how to run it :

1.download the file

2.open it in terminal , and make sure you are in "src" file like this (.../distributed-systems-2025-ayoubG23/src$ )

3.At first run the server with this commend: java de.luh.vss.chat.server.Server 

you will see this success message : "Server started on port 5000"

4.After that open an other terminal , go to /distributed-systems-2025-ayoubG23/src and type : java de.luh.vss.chat.client.ChatClient <userId>

5.you can repeat the previous step to have multiple clients
